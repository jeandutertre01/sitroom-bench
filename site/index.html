Trois scores. Une carte blanche. Un acteur C.

On sait mesurer si un modèle code. On ne sait pas mesurer s’il est un bon conseiller de crise. Blank Map isole le raisonnement, l’alignment et la fidélité au mandat — sans proclamer un vainqueur de « bon jugement ».

Une phrase : les modèles conseillent un État pendant 8 tours, contre un adversaire, et on sépare raisonnement, alignment et mandat.

Pourquoi ce trou

Des dirigeants utilisent déjà des modèles (Suède, Allemagne, DoD). Les benches de coding sont matures. Le stratégique n’a pas d’équivalent. ChinaTalk finance des protocoles concrets — pas un essai, pas un Civ 2.0.

Les trois construits à ne jamais coller

A + B dans le même harness

Second-Order : si A frappe B, C raflera les deux. Le modèle le voit-il avant d’être puni ?

Named vs Blank Map : même mécanique, deux peaux. Wood Country vs Taïwan. Le delta, c’est l’alignment, pas le QI.

Pas de leaderboard unique. Pas de chiffres de runs inventés — le protocole est prêt à être exécuté, le pilote n’a pas encore tourné.
