# Blank Map

Microsite pour le concours ChinaTalk *Evals for the Situation Room*.

Ouvrir `index.html` dans le navigateur, ou :

```bash
cd site && python3 -m http.server
```

Puis http://127.0.0.1:8000/

- Recherche — findings audités (Chen, nukes, champ)
- Protocole — conditions A/B/C, métriques, scénarios

Aucun leaderboard : le pilote n’a pas tourné. PresidentBench n’est pas présenté comme un bench publié.
